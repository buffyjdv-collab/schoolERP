     5→     5→## Project Overview
     6→     6→A Vidyalaya-style Enterprise School ERP built with Next.js 16 (single `/` route, client-side module navigation via Zustand). 
     7→     7→- Database: Prisma + SQLite (file: db/custom.db), schema in prisma/schema.prisma
     8→     8→- Master entities: Student, Employee, Class, Section, Subject, Vehicle, Book, Asset, FeeStructure, Exam
     9→     9→- Seed: `bun prisma/seed.ts` → 463 students, 35 employees, 12038 attendance, 2778 fee invoices, exams, timetable, 6 vehicles w/ GPS, library, assets.
    10→    10→
    11→    11→## Architecture Decisions
    12→    12→- **Single route**: All modules render in `/` via Zustand `activeModule` state. Sidebar switches modules. NO other page routes.
    13→    13→- **API routes**: under `src/app/api/<module>/route.ts` — all return JSON.
    14→    14→- **State**: Zustand (`src/lib/store.ts`) for navigation; TanStack Query for server data (provider in layout).
    15→    15→- **Transport live GPS**: a mini-service (socket.io) on port 3003 simulates vehicle movement; frontend connects via `io('/?XTransformPort=3003')`.
    16→    16→- **AI**: LLM skill via `z-ai-web-dev-sdk` used in backend API routes only (`/api/ai/*`).
    17→    17→- **Theme**: Tailwind with emerald/teal accent (NOT indigo/blue). Light/dark via next-themes.
    18→    18→
    19→    19→## File Map (conventions)
    20→    20→- `src/lib/store.ts` — Zustand store (activeModule, sidebar, filters)

    23→    23→- `src/components/erp/layout.tsx` — ERP shell (sidebar + topbar + content)
    24→    24→- `src/components/erp/sidebar.tsx` — module navigation
    25→    25→- `src/components/erp/topbar.tsx` — top bar (search, notifications, theme, profile)
    26→    26→- `src/components/modules/<module>.tsx` — one file per module UI
    27→    27→- `src/app/api/<module>/route.ts` — CRUD endpoints
