# Task 12 — ui-modules (library, hr, communication, assets)

## Task
Build 4 module UI files for the Enterprise School ERP:
1. `src/components/modules/library.tsx` → `LibraryModule`
2. `src/components/modules/hr.tsx` → `HrModule`
3. `src/components/modules/communication.tsx` → `CommunicationModule`
4. `src/components/modules/assets.tsx` → `AssetsModule`

## Work Log
- Read worklog.md and reviewed existing conventions: dashboard, admissions, academics, attendance, exams modules; primitives (StatCard, SectionHeader, StatusBadge, EmptyState); types.ts; api.ts; sidebar.
- Reviewed relevant API routes to confirm response shapes (library/books, library/issues, library/issues/[id]/return, hr/employees, hr/leaves, hr/leaves/[id], hr/payroll, hr/payroll/run, communication/notifications, communication/send, ai/compose, assets).
- Wrote `library.tsx` (370 lines): 4 StatCards (Total Books, Available Now, Issued, Overdue/Fined) + Tabs (Catalog / Issued Books). Catalog tab has debounced search (350ms via setTimeout closure on the search handler — no set-state-in-effect) calling `api.library.books(q)`, color-coded availability counts, and an Issue dialog with a searchable student picker sourced from `api.students.list()`. Issued tab highlights overdue rows with rose tint and includes a Return button calling `api.library.return`.
- Wrote `hr.tsx` (448 lines): 4 StatCards (Total Employees, On Leave Today, Pending Leave Requests, Monthly Payroll Cost) + Tabs (Employees / Leave Requests / Payroll). Employees tab is searchable + department filter, row click opens a detail dialog. Leaves tab has HOD Approve / Principal Approve / Reject buttons for Pending rows (calls `api.hr.approveLeave`) plus a day-count display. Payroll tab has `<input type="month">` selector defaulting to current month, a Run Payroll button (calls `api.hr.runPayroll`), a totals row at the bottom (sum of basic/allowances/deductions/net), and a Mark Paid action that toasts "Payslip generated".
- Wrote `communication.tsx` (324 lines): SectionHeader "Communication Center" + 4 StatCards (SMS Sent, Email Sent, WhatsApp, Failed) computed from `api.communication.list()`. Two-column layout — left (lg:col-span-1) is a Compose card with: a 4-button channel selector (SMS/Email/WhatsApp/Push) with accent colors, recipient input, conditional subject input (Email only), a prominent AI Compose panel (highlighted with primary/30 border + gradient) that takes topic + audience and calls `api.ai.composeMessage({channel, topic, audience})` to fill the message textarea (and subject for email), a message textarea with live char count, a Category select, and a Send button calling `api.communication.send`. Right (lg:col-span-2) is a Message History table with channel icon+badge, recipient+content (truncated), category, status, and time, filterable by channel via a Select and searchable.
- Wrote `assets.tsx` (284 lines): 4 StatCards (Total Assets, Total Value, In Good Condition, Needs Repair) + a BarChart (recharts) of asset value by category with multi-color Cells (emerald/teal/amber/rose/violet/sky palette — no indigo/blue) + a filterable Asset Register. The register supports search input, category Select, condition Select, and a Group toggle that switches between a flat table (with a totals footer row) and a grouped view (assets grouped by category with sticky sub-headers showing per-category subtotals in a card grid layout). Rows are tinted rose for Damaged and amber for Under Repair, and clicking a row toasts the asset name + value.
- Lint fixes: removed an unused `Label` import and an unused `fmtDate` helper from assets.tsx. Moved a `Cell` recharts import to the top-level imports block (it had initially been placed at the bottom of the file). Simplified the assets footer to use a single `colSpan={7}` cell with a flex inner layout so column counts match across mobile/desktop breakpoints without relying on `display:none` column-span interactions.
- Dev conventions followed throughout: `'use client'` first line; `useQuery`/`useMutation`/`useQueryClient` from `@tanstack/react-query`; `api` from `@/lib/api`; types from `@/lib/types`; shared primitives `StatCard, SectionHeader, StatusBadge, EmptyState` from `@/components/erp/primitives`; shadcn `@/components/ui/*` (card, button, input, label, textarea, badge, skeleton, tabs, table, dialog, select); `lucide-react` icons; `sonner` toast; `recharts` charts; emerald/teal accent only (NO indigo/blue); responsive mobile-first with sm/md/lg/xl breakpoints; tables wrapped in `max-h-[60vh] overflow-y-auto scroll-thin` containers with sticky headers; date formatting via `new Date(x).toLocaleDateString('en-IN', { day:'2-digit', month:'short', year:'numeric' })`; INR formatting via `Intl.NumberFormat('en-IN', { style:'currency', currency:'INR', maximumFractionDigits: 0 })`.
- Effect-free pattern: used `effectiveX = state || (data[0]?.id ?? '')` style and onChange-based state resets. The library search uses a setTimeout closure attached to the handler function (`(onSearch as any)._t`) for debouncing — no useEffect, no set-state-in-effect ESLint violations.
